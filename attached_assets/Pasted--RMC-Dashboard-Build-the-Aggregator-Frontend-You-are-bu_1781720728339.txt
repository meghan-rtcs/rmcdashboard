# RMC Dashboard — Build the Aggregator + Frontend

You are building a KPI dashboard for Real Management Company (RMC). The backend infrastructure is already in place (appfolio.js, db.js, sync.js, server/index.js). You need to build TWO files:

1. `server/lib/aggregator.js` — queries SQLite + live AppFolio API calls → returns dashboard JSON
2. `public/index.html` — single HTML file that loads React via CDN and renders the entire dashboard

## CRITICAL: The design MUST match the Limehouse dashboard exactly

This dashboard is a re-skin of an existing Limehouse PM dashboard. The EXACT same layout, spacing, component patterns, chart types, and interaction model must be replicated. The ONLY changes are:
- **Branding**: RMC colors instead of Limehouse green
- **Data source**: AppFolio instead of Buildium/RentEngine
- **No LeadSimple tab**: replaced with a "Leasing & Marketing" tab
- **Source pills**: show "AF" (AppFolio) instead of "BD"/"RE"

## ARCHITECTURE: Multi-file frontend loaded by HTML

The frontend has this structure (same as Limehouse):

### `public/index.html` (entry point, ~85 lines)
Loads React 18 + Babel from CDN, fetches `/api/dashboard`, stores result on window, then loads component scripts in order via `<script type="text/babel" src="...">` tags:
```
1. components/shared.jsx    — all reusable components (Sparkline, KPI, charts, etc.)
2. components/dashboard.jsx — main dashboard + CEO view + Leasing tab
3. app.jsx                  — root App component, renders everything
```

### `public/components/shared.jsx` (~580 lines)
This is the COMPLETE component library. Port the ENTIRE Limehouse shared.jsx but with RMC colors:
- `fmt` — number/money/percent/delta formatters
- `Sparkline` — inline SVG sparkline (used in every KPI tile)
- `DeltaPill` — green/red YoY delta badge
- `SourcePill` — data source badge (change to show "AF" for AppFolio with gold color)
- `SectionHeader` — uppercase section label with horizontal rule
- `Modal` + `DrillTable` — click-to-drill data tables
- `MiniBars` — single-series bar chart with hover tooltips
- `DualBars` — dual-series bar chart (e.g., rent collected by 3rd vs 10th)
- `Donut` — ring chart for categorical breakdowns
- `LineChart` — multi-series line chart with axes, gridlines, hover crosshair + tooltip
- `HBars` — horizontal bar chart (for aging buckets, source breakdown)
- `Funnel` — step funnel visualization (prospects → showings → apps → move-ins)
- `DashHeader` — sticky header with logo, sync status, date range selector, sync button

The SourcePill map should be:
```js
const map = {
  AF: { label: 'AF', title: 'AppFolio', color: '#D4881A', bg: 'rgba(212,136,26,0.08)' },
};
```

## AGGREGATOR (`server/lib/aggregator.js`)

Reference METRIC-MAPPING.md for every calculation. The aggregator must return:

```js
{
  dashboard: {
    meta: { syncedAt, totalUnits, totalProperties, totalOwners, activeLeases },
    occupancy: { rate, totalUnits, occupied, vacantNotRented, vacantRented, avgDaysVacant, doorsAdded, doorsLost, netDoors, ownersTotal },
    leasing: { renewalRate, renewalsCount, mtmLeases, fixedLeases, appsSubmitted, moveins, appsPerMovein },
    financials: { delinquent, delinquentCount, delinquencyRate, avgRentPerDoor, grossIncome, netIncome, rentCollectedBy3rd, rentCollectedBy10th },
    marketing: { inquiries, activeProspects, showingsTotal, showingsCompleted, showingCompletionRate, noShows, unitsOnMarket },
    maintenance: { openWorkOrders, avgDaysToComplete },
    // Chart data arrays (12 months):
    rentCollectionByMonth: [{ month, by3rd, by10th }],
    incomeMonthly: [{ month, gross, net, expense }],
    occupancyTrend: [{ month, rate }],
    doorsMonthly: [{ month, added, lost }],
    renewalsByMonth: [{ month, renewed, notRenewed }],
    agingBuckets: [{ label, amount, color }],
    inquiryBySource: [{ source, count }],
    marketingFunnel: [{ label, value }],
    spark: { occupancy:[], delinquent:[], renewalRate:[], doorsAdded:[], doorsLost:[], avgRent:[], ... },
  },
  drilldowns: {
    occupancy: { title, cols, rows },
    delinquent: { title, cols, rows },
    renewalRate: { title, cols, rows },
    // ... one per drillable metric
  },
  sync: { lastSync, status, duration }
}
```

Each KPI uses the buildKpi pattern:
```js
function buildKpi(value, prevYear = 0, opts = {}) {
  return { value: value ?? 0, prevYear: prevYear ?? 0, ...opts };
}
```

The aggregator can make LIVE AppFolio API calls for data that's better fresh (like income_statement_12_month for chart trends). Import the appfolio client:
```js
import { appfolio } from "./appfolio.js";
```

For sparklines, build 12-element arrays from monthly data (one value per month for trailing 12 months).
