### Role: Bookkeeping Coordinator
- **Abbrev**: BC
- **People**: 1 person
- **KPIs**:

**4. Reconciliation Accuracy**
- Source badge: BD
- Target: 100%
- Direction: higher is better
- Format: percentage

- Data: from `GET /v1/bankaccounts/{bankAccountId}/reconciliations`. Pull reconciliation records for each bank account. If not yet cached, add to the Buildium sync.

**5. Rent Processing Accuracy**
- Source badge: BD
- Target: 100%

- Data: from `GET /v1/leases/{leaseId}/transactions` — look for reversed payment transactions as the error signal.

**6. Vendor Compliance**
- Source badge: BD
- Target: 100%
- Direction: higher is better
- Format: percentage

- Data: from `GET /v1/vendors?status=Active`. Check `VendorMessage.TaxInformation.TaxPayerId` for W-9 and `VendorMessage.VendorInsurance.ExpirationDate` for COI.

**7. 1099 Compliance**
- Source badge: BD
- Target: 100% by Jan
- Direction: higher is better
- Format: percentage
- Formula: `(vendors where IncludeIn1099=true AND TaxPayerId is not empty) / (total vendors where IncludeIn1099=true) × 100`
- Data: same vendors endpoint. Filter to `TaxInformation.IncludeIn1099 == true`, check if `TaxPayerId` is populated.
